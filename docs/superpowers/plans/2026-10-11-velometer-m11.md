# velometer M11 reader features: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a reader see how every quoted report measures beside our approach, then cite,
download, link to and find exactly what they saw. All of it works in the live app and in the
static edition.

**Architecture:**
- The server renders the data behind each feature, either into the page as JSON or into
  `/data/search.json`:
  - Sources rows;
  - citation fields;
  - theme tokens;
  - the search index.
- Small pure ES modules do the interaction (`cite.js`, `download.js`, `permalink.js`,
  `search.js`), and thin UI modules wire them into the page.
- No new server route depends on reader state, so the M9 export keeps writing plain files.

**Tech Stack:** FastAPI/Jinja2, Pydantic v2, plain ES modules tested with `node --test`,
pytest, `tools/render_pass.py` (headless Chrome + axe-core 4.13.0).

**Spec:** `docs/superpowers/specs/2026-10-11-velometer-m11-design.md`

## Global Constraints

- OSM figures are "mapped km" (ADR 0006). No construction verbs for OSM figures, including in
  citation titles and download source lines.
- Licences (ADR 0008): ODbL attribution in every download and every citation:
  "Map data © OpenStreetMap contributors, ODbL 1.0".
- The app's only external host stays `tile.openstreetmap.org`. No npm packages, no build step.
- Never write `velometer.sqlite`. Its md5 is a5222dc40ff57131fc2f900a7c285bce and is
  unchanged by the whole milestone.
- Never type OSM ids from memory.
- Tests assert rules, not today's values. Each feature has a test that fails without it.
- The M10 rules hold:
  - colours only as tokens, with no literal outside the two token blocks of `app.css`;
  - 4.5:1 text and 3:1 non-text contrast;
  - `table.stack` with `data-label` for data tables;
  - a visible `:focus-visible` ring;
  - zero axe violations in the render pass;
  - announcements through `live.js` `announce(text)`.
- Every internal URL in a template goes through `u()`, and every URL in JS through `url()`
  (`static/js/base.js`). Scripts are `type="module"` files under `/static`, and JSON goes in
  `<script type="application/json">`.
- No displayed number, run, classifier or DB change. The live app and the static edition behave
  the same.
- Gate:
  `uv run ruff format --check . && uv run ruff check . && uv run pytest && node --test "src/velometer/app/static/js/tests/*.test.mjs"`.
- Commits end with one trailer, `Assisted-by: Claude:<model-id>`. Never use Co-Authored-By.
  Never push. Stage explicit paths.

## Facts the tasks rely on (verified 2026-10-11)

- **Figure sources** are figure-source ids, not content `Source` records. They are
  `clean_cities_2025`, `qecio_v2_10`, `bikenetkit_v1`, `official`, `changing_cities` and
  `mobilitaetsagentur_wien`.
  - `config/organisations.yaml` maps `{city, source, organisation}`, where `city` is a city id
    or `"*"`. `official` maps to `senmvku` for berlin and to `copenhagen_kommune` for
    copenhagen.
  - The display names are `DifferencesConfig.source_names` (`config/differences.yaml`).
  - The quoted (city, source) pairs are `check._figure_pairs(config_dir)` (figures.csv) plus
    `check._reconcile_sources` (reconcile.yaml).
- An **organisation profile** (`content/organisations/<id>.yaml`, model `Organisation`) has
  `sections: list[OrgSection]`. The "How they measure" section carries
  `dimensions: dict[str, str]`, whose keys are the six ids
  `scope, kind, length, date, area, method` and whose values are prose with `[@source-id]`
  citations. Not every profile has all six today.
- **Ranking models** (`src/velometer/config.py:414-443`): `PresetRanking(kind, id, label,
  preset)`, `ExternalRanking(..., source, ...)` and `ExternalRatioRanking(..., source, ...)`.
  - `ReportData.preset_labels()` is at `report/data.py:188`.
  - The overview headers are at `templates/index.html:95-100` (key numbers) and `:129`
    (rankings, `rankings_table` at `main.py:468`).
- **Charts:**
  - `static/js/data.js` `mount(el, draw)` returns `off`.
  - `drawAll(draw)` finds `[data-chart]`. Other containers are `[data-compare-chart]`,
    `[data-story-plot]` and `.plan-chart[data-plan-item]`.
  - Every chart container has `aria-describedby` pointing to a `<summary>` or `<caption>` id of
    its data table (M10). The cities-page sparklines (`.spark-mount`) are decorative and have no
    table.
- **Page helper:** `page(request, name, active, data=None, status_code=200, **ctx)`
  (`main.py:396`).
  - The footer has `footer.classifier` and `footer.config`.
  - `static_edition` is a Jinja global, `{"commit": short}` in the export and None live.
  - The per-run fields (`run_id`, `osm_timestamp`, `classifier_version`) come from
    `data.csv_rows(city_id)`.
  - The commit comes from `short_commit(git_commit())`.
- **CSV preamble:** `report/csvexport.py` `ATTRIBUTION` and `csv_preamble(commit, generated_at)`
  write two `#` lines.
- **Export:** `export.PAGES` (`export.py:48`) is a fixed list, and per-city URLs come from
  `export_urls`.
- **Tier map:** `static/map.js` is an IIFE. It reads `#tiermap-config`, uses radios
  `input[name=kind]` and checkboxes `input[name=tier]` (A–E), and calls `map.fitBounds(bounds)`
  in `show()`. It keeps no URL state.
- **Story:** `static/js/story.js` `mark(step)` / `show(step)`, driven by an
  IntersectionObserver. It does not use the hash.
- **Nav:** `templates/_nav.html` is a `<ul>` of `item(key, href, label)`. `static/js/nav.js`
  handles the phone menu and Escape.
- **Test fixtures:**
  - `tests/test_app.py` has `client` / `setup` (fixture DB with berlin and paris, shipped
    content).
  - `tests/test_a11y.py` has `all_page_urls` (from `export.export_urls`).
  - Shared JSON cases follow `tests/url_cases.json`. The node test reaches it with
    `new URL("../../../../../../tests/<file>.json", import.meta.url)`.
- **Render pass:** `tools/render_pass.py` provides:
  - `Steps.check(name, why, detail)`, `tab_to(t, sel)`, `press(t, key)`, `click(t, sel)`,
    `IDREFS_JS` and `audit(t)`;
  - the sections `_compare`, `_map_steps`, `_skip_link` and others, run by `keyboard()`.

## Review Focus

1. **Citing on the static edition under `/velometer/` with a permalink state.** The absolute URL
   in every format must include the base path and the current query or hash. Pinned in
   Task 3's node cases and Task 4's render step.
2. **Downloading while the OS is in dark mode.** The SVG and PNG must carry the light-theme
   colours. A dark value that maps ambiguously to light would silently miscolour. Pinned in
   Task 5: a `lightOf` unit test plus a pytest rule that the dark→light value map is
   unambiguous for every token a chart can draw with.
3. **Permalinks with stale or hostile values:** an unknown kind, tiers `"XYZ"`, zoom 99,
   `at=NaN,1`, a step that no longer exists. Each falls back to that control's default with no
   error and no console message. Pinned in Task 6's node tests.
4. **Search with no match, accents, mixed case, multiple words or leading spaces.** "krakow"
   finds Kraków. "Vienna" finds Wien. A miss shows an announced "No match", and Enter does
   nothing on it. Pinned in Task 7's node tests.
5. **A figure source added to figures.csv whose organisation lacks a complete, cited "How they
   measure" section.** `content --check` must fail and name it. Pinned in Task 2.

- Produces:

```python
@dataclass(frozen=True)
class CiteFields:
    title: str            # "Berlin, headline (A+B km per 100 km of main roads), city proper (LAU), Oct 2026"
    path: str             # the page path without base, e.g. "/city/berlin/time"
    osm_timestamp: str | None   # ISO, from the run; None for multi-city views
    snapshot_note: str | None   # multi-city: "OSM snapshots of 2026-10-03 to 2026-10-05"
    classifier: str       # "v4"
    run_id: str | None
    commit: str           # short_commit(git_commit())
    attribution: str = "Map data © OpenStreetMap contributors, ODbL 1.0"


def fields_for_city(data, city_id: str, title: str, path: str, kind: str = "lau") -> CiteFields
def fields_for_cities(data, city_ids: list[str], title: str, path: str) -> CiteFields
def cite_text(f: CiteFields, accessed: str | None = None, url: str | None = None) -> str
```

  JS (`cite.js`), with the same field names in camelCase-free JSON (`asdict` keys):

```js
export function citeText(f, accessed = null, url = null) {}   // string, identical to Python
export function citeBibtex(f, accessed, url) {}              // string
export function citeCsl(f, accessed, url) {}                 // object (CSL-JSON item)
export function absoluteUrl(path, loc = globalThis.location, doc = globalThis.document) {}
// origin + base (from <meta name="velometer-base">) + path(no leading slash) + loc.search + loc.hash
```

  - **Readable text:**
    `velometer (<year>). <title> [Data set]. <snapshot>; classifier <v>; run <id>; commit <c>. <attribution>. <url> (accessed <accessed>).`
    - `<year>` is the year of `osm_timestamp`, else of the last date in `snapshot_note`.
    - `<snapshot>` is `OSM snapshot <osm_timestamp>`, or `snapshot_note`.
    - "run <id>; " is omitted when `run_id` is None.
    - Without a url, the text ends at "<attribution>."; with a url but no accessed date, it ends
      "<url>.".
  - **BibTeX:** `@misc{velometer_<slug>_<yyyymmdd>,` with these fields:
    - `author = {{velometer}}`;
    - `title = {<title>}`;
    - `year = {<year>}`;
    - `howpublished = {\url{<url>}}`;
    - `note = {<snapshot>; classifier <v>; run <id>; commit <c>. <attribution>. Accessed <accessed>}`.
    - `<slug>` is the title lowercased, non-alphanumerics → `_`, trimmed to 40 characters.
    - Escape `{`, `}`, `%`, `&`, `#` and `_` in values.
  - **CSL-JSON:** `{type: "dataset", id, title, author: [{literal: "velometer"}],
    issued: {"date-parts": [[year]]}, accessed: {"date-parts": [[y, m, d]]}, URL: url,
    note: "<snapshot>; classifier <v>; run <id>; commit <c>. <attribution>.", version: commit}`.
