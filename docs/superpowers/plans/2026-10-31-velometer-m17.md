# velometer M17 (findable, citable, published from GitHub): Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** both live sites carry crawl files, page descriptions and dataset markup, code and data
have Zenodo DOIs, and a deploy runs on GitHub after the user's approval click, at no added cost.

**Architecture:**
- **Crawl files and head data:** the public export and `datalab build` generate them from their
  own page lists. `deploy-check` validates them.
- **Workflows:**
  - `ci.yml` runs the gate on synthetic fixtures.
  - `deploy.yml` fetches the data snapshot and tiles from the existing server over a no-sudo
    `ci` key, then exports, runs the R64 passes in the runner and deploys with
    `tools/server.py`.
- **Zenodo:** one software record via the GitHub integration, and one dataset record uploaded by
  hand.

**Tech Stack:**
- Python 3.12, uv, Typer, Pydantic v2, Jinja2, FastAPI TestClient export, pytest, ruff.
- GitHub Actions (pinned SHAs), Caddy 2.11.4, Playwright Chromium (render_pass), Zenodo.

**Spec:** `docs/superpowers/specs/2026-10-31-velometer-m17-design.md` (approved 2026-10-31,
§4.7 holds the settled builder questions). Read it with this plan.

## Global Constraints

- **No additional costs:** no paid service, storage or runner (spec §2.7).
- **Publishing:**
  - Nothing publishes without the user's approval, given either as a typed go or as the GitHub
    `production` environment approval for `deploy.yml`.
  - `setup`, `unlock`, `golive-check --host` and `deploy tiles` stay local.
- **Secrets:** never write a raw value into any file. Wire secrets through direnv + `pass`. The
  CI key's pass entry is `velometer/ci-deploy-key`.
- **The database:** `velometer.sqlite` md5 stays `bc7225af0cc4b50753c1d73fe19298be`; never
  write it.
- **Deleting:** no `rm -rf`, including in workflow files, scripts and briefs.
- **Reader-facing text:** new reader-facing sentences ship only after the user reviewed them.
  This covers meta descriptions, `llms.txt`, the home sentence, the data README and the Zenodo
  description.
- **Original terms:** English terms in German prose get `<i lang="en">` or `<span lang="en">`.
- **Tests:**
  - Tests assert the rule, not today's value, and are red-proofed by breaking the rule.
  - A `ResourceWarning` fails the run.
- **Commits:**
  - One trailer, `Assisted-by: Claude:claude-opus-5-5`.
  - Stage explicit paths. Never the Gmail address. The git identity comes from global config.
- **OSM ids:** never typed from memory.
- **The gate:**
  - `uv run ruff format --check . && uv run ruff check . && uv run pytest && node --test "src/velometer/app/static/js/tests/*.test.mjs"`
  - Run ruff unsandboxed (sandbox stub files).
- **Fixed values:**

  | Name | Value |
  |---|---|
  | `site.url` | `https://velometer.zaehlwerk-datalab.de/` |
  | Datalab | `https://zaehlwerk-datalab.de/` |
  | ODbL URL | `https://opendatacommons.org/licenses/odbl/1-0/` |
  | Creator | Person "Dennis Senzel" |

- **Index:**
  - Non-index paths: `/data/`, `/maps/`, `/tiles/`, `/build.json`, `/city/*/panel`, plus the
    same under `/de/`.
  - Index: every other exported HTML page, both editions, except legacy `/methodology/de`, which
    is canonical to `/de/methodology`.
- **Sitemap alternates:** `en`, `de`, and `x-default` → en. They must be reciprocal.
- **`lastmod`:** never later than the real content change, and stable across no-change
  rebuilds.

## Review Focus

1. **A preview or local export** (no `--public`) must emit no absolute URL, no `robots.txt`
   allowing indexing, and no sitemap. A preview indexed by accident would compete with the live
   site.
   - Test: `test_preview_export_has_no_crawl_files` in Task 3.
2. **A city without a German narrative, or without subarea CSVs:** the sitemap, the
   descriptions and the city `Dataset` must not break or invent text.
   - Tests: `test_sitemap_city_without_subareas` (Task 3) and
     `test_description_falls_back_without_dek` (Task 5).
3. **JSON-LD with quotes, `<` or `&` in a narrative** must stay valid JSON and must not close the
   script element. Use `</` escaping as `<\/`.
   - Test: `test_jsonld_escapes_script_close` in Task 6.
4. **The `ci` key** must not be able to run anything outside the deploy and snapshot-read
   forms: no shell, no `sudo`, no path outside `/srv/{velometer,datalab}/releases`,
   `/srv/snapshot`, `/srv/tiles`.
   - Tests: `test_gate_rejects_*` in Task 9.
5. **A deploy run whose passes report findings, or whose snapshot sha256 mismatches,** must stop
   before any upload.
   - Tests: the workflow-structure tests `test_deploy_steps_order` and
     `test_deploy_fails_closed_on_sha` in Task 10.
